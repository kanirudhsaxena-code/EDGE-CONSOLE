# Output Contracts

- `edge-stocks-output.schema.json` — legacy EDGE Stocks V1.1 contract retained for compatibility/history.
- `edge-stocks-output-v1.2.schema.json` — **DEPRECATED / historical only**.
- `edge-stocks-output-v1.3.schema.json` — **CANONICAL** for new `EDGE <stock/company/ticker>` outputs.

V1.3 uses the Efficacy V2 order: EDGE MASTER ASSESSMENT → ACTIVE CALLS → CURRENT STOCK OUTCOME → DRILL-DOWN. VERIFIED components require meaningful evidence-grounded Key Outcome + Interpretation. OFFICIAL and PROVISIONAL efficacy remain distinct. V1.2 must not be selected for new runs.
